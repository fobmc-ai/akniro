# Definition of Done

An architecture or implementation change is done only when:

- scope is classified A/B/C and linked to stable IDs;
- ownership and module boundaries are explicit;
- API/event/schema compatibility is assessed;
- security, realtime, offline, observability, migration, and rollback impacts are reviewed;
- tests or validation evidence exist at the appropriate level;
- documentation, index, ADR, and architecture changelog are updated;
- AI-generated changes have human review and required approval gates;
- no unresolved MUST/MUST NOT conflict remains.
