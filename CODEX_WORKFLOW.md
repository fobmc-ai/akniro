# Codex Development Workflow

1. Read `AGENTS.md` and the minimal indexed context.
2. State scope, A/B/C status, assumptions, affected IDs, and context level.
3. Inspect only bounded files and contracts needed for the task.
4. Produce a plan and identify any ADR requirement.
5. Patch the smallest coherent change.
6. Run contract, migration, security, realtime, and relevant tests.
7. Review diff for ownership, compatibility, audit, and rollback.
8. Update indexes/changelog/ADR and report evidence plus remaining risks.
