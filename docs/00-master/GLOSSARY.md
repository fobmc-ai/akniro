# Glossary

- **Machine Project:** versioned, deployable source of truth for one machine/cell and its platform applications.
- **Edge:** local execution environment capable of minimum operation without cloud.
- **Control Plane:** desired state, policy, identity, lifecycle, and deployment management.
- **Data Plane:** live runtime execution and observations.
- **Tag:** typed, addressable value with quality, timestamp, ownership, and access policy.
- **Capability:** versioned declaration of a platform function and its contract.
- **Projection:** derived read model; never the canonical owner.
- **Agent:** policy-constrained AI actor with explicit tools, context, and approval gates.
- **Degraded Mode:** declared reduced-function behavior under fault or resource loss.
