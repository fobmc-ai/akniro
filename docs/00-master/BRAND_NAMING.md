# Brand Naming — 织能 Zhinen

## Formal identity

- Chinese brand: **织能**
- English brand: **Zhinen**
- Product category: AI-native Industrial OS / industrial automation platform
- Project repository slug: `zhinen-platform`

## Meaning

“织” represents the integration of machines, control, data, workflows, people, and AI. “能” represents capability, energy, and the ability to execute safely in the real world. The name is intentionally broader than PLC, HMI, or AI so the product family can grow without a rename.

## Product family

| Product | Role |
|---|---|
| Zhinen OS | unified industrial platform |
| Zhinen Studio | engineering and project environment |
| Zhinen Control | PLC, motion, robot, and realtime control |
| Zhinen Edge | offline-capable edge runtime |
| Zhinen Intelligence | governed AI engineering assistant |
| Zhinen App Center | signed apps, plugins, and drivers |

## Naming rules

- Use `织能` in Chinese-facing product surfaces and `Zhinen` in English-facing technical identifiers.
- Do not use `Industrial OS` as the standalone brand name.
- Product names MUST describe a stable platform capability, not an implementation detail.
- Domain, trademark, and package availability MUST be checked before public launch.
