# ADR-0003: V0.1 Foundation Skeleton

- Status: accepted
- Date: 2026-09-08
- Scope: CORE-FOUNDATION-001

## Decision

V0.1 begins with a contract-first source skeleton, JSON Schemas for Machine Project, Capability, and Resource Lease, and bounded source areas for Core, Runtime, Engineering, Platform, and AI. No external runtime dependency is introduced yet.

## Consequences

The repository can start parallel development safely while technology choices and large business implementations remain deferred. Schema validation and interface tests are the next implementation gate.
